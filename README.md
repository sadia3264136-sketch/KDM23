# 👟 KADAM SHOES - Luxury Footwear Store

Fully responsive, high-performance Shoe E-Commerce Store with Admin Panel, NayaPay Card Payment, Cash on Delivery, and live color/size selectors.

## 🚀 How to Deploy on Vercel:

1. **Option A: Drag & Drop Folder or GitHub**
   - Extract this ZIP file.
   - Push to your GitHub repository.
   - Go to [Vercel Dashboard](https://vercel.com/dashboard).
   - Click **"Add New Project"** -> Import your GitHub repo.
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Click **Deploy**!

2. **Option B: Vercel CLI**
   ```bash
   npm install
   npx vercel
   ```

## 💎 Features:
- 👟 Shoes catalog with multi-color swatches, size selection (39-45)
- 💳 NayaPay Debit Card Gateway Simulation + Cash on Delivery (COD)
- ⚙️ Admin Dashboard (Password: `admin123`) to manage stock, orders & prices
- 📱 Responsive design with Tailwind CSS & Framer Motion
